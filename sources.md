## Research Notes
- MCP focuses on vertical integration (agent ↔ tools/data)
- A2A focuses on horizontal integration (agent ↔ agent)
- Both are open standards for AI agent ecosystems
- MCP uses JSON-RPC 2.0 over stdio/HTTP
- A2A uses structured JSON over HTTP
